Common questions

Is a draft visible to anyone?

No. The draft stays yours until you post it.

Can I still write it elsewhere?

Yes. RFP Intake takes a document you already wrote and turns it into the same fields.

Does drafting publish it?

No. A drafted requirement goes on the board when you decide it does, and ConvergX can still decline it.
