Role-Gated Portals
Is this a security control?

Read it as a description of how the system behaves, not as an assurance. No third-party security audit is on record for this platform.

What enforces the boundary?

The application itself, rather than whatever signed the user in.

Can I be shown it working?

Yes. Where a behaviour is load-bearing for your review, ask ConvergX to demonstrate it in the running system before you rely on it.
